🔬 난임 환자 대상 임신 성공 여부 예측 AI 온라인 해커톤
2026.03.13 – 03.20 3인 팀 (5조 오조스) | 데이터 전처리·피처 엔지니어링·모델링·앙상블·발표
256,351건 IVF 시술 기록으로 임신 성공 여부를 예측하는 이진 분류 문제. 클래스 불균형(성공 25.8%), 99% 결측 컬럼, 텍스트형 수치 등 난제를 의학 논문 근거와 함께 해결.
  • 리더보드 3위 — AUC 0.74221 (1위 0.74235와 단 0.00014 차이)
  • GBDT 3종(XGBoost 59.1% + LightGBM 19.5% + CatBoost 21.4%) + PyTorch MLP 25% 이종 앙상블
  • SHAP 분석 + 의학 논문 3편 근거로 파생 피처 23개 직접 설계 (이식_Day5★, 나이×배아수 교호작용 등)
  • 클래스 불균형 → scale_pos_weight=2.87, 고결측 → 결측 플래그 피처화, 범주형 → Target Encoding K-Fold OOF
  • Optuna 하이퍼파라미터 자동 탐색 + Nelder-Mead 앙상블 가중치 수학적 최적화
  • 10-Fold Stratified K-Fold 검증 전략, MLflow 실험 관리, Git Flow 협업 전략 적용
  • PyTorch ResidualBlock MLP (Input→512→Residual×2→256→128) — GBDT가 놓친 복합 교호작용 패턴 포착
